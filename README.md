# 세계 국기 카드

여섯 살 아이가 나라 이름을 익히도록 만든 국기 학습 카드입니다.
카드를 누르면 나라 이름이 나오고, 한 번 더 누르면 다음 나라로 넘어갑니다.

**👉 [바로 열기](https://geonyongkim.github.io/flag-cards/)**

## 무엇이 들어 있나

- 독립국 **197개국** 국기. 벡터(SVG)라 화면을 키워도 깨지지 않습니다
- 단계 선택 — 쉬워요 30 / 보통 70 / 전부 197, 그리고 대륙별 6가지
- "쉬워요"는 대한민국부터 아이에게 익숙한 순서로 나옵니다
- 처음 본 나라마다 별이 쌓입니다(브라우저에 저장되어 다시 열어도 남습니다)
- 태블릿을 눕히면 왼쪽 카드 · 오른쪽 조작부 2단으로 바뀝니다
- 어두운 곳에서는 화면이 어두운 색으로 알아서 바뀝니다

- **수도 퀴즈** — 위쪽 `🃏 국기 카드 / 🏙️ 수도 퀴즈 / 🗼 랜드마크`로 바꿉니다(마지막 고른 모드를 기억)
  - 주요 50개국만 냅니다. 국기와 나라 이름을 보여주고 "이 나라의 수도는?" 4지선다
  - 오답 보기는 같은 대륙에서 먼저, 모자라면 50개국 전체에서 채웁니다(수도명 중복 없음)
  - 맞히면 별이 터지고 "딩동댕!", 틀리면 정답을 초록으로 보여주고 "괜찮아요!"
  - 한 판 10문제(아프리카는 8개국이라 8문제). 틀린 나라는 판 끝에 한 번 더 복습
  - 끝나면 별 개수 요약과 "다시 하기". 숫자키 1~4로도 고를 수 있습니다
  - 짧은 효과음은 파일 없이 WebAudio로 냅니다. `🔊 소리` 버튼으로 끌 수 있습니다
  - 맞힌 나라는 머리의 🏆로 쌓입니다(카드 모드의 ⭐와 별개, `flagcards.capitals`에 저장).
    저장이 막힌 브라우저에서도 퀴즈는 그대로 됩니다

- **랜드마크 퀴즈** — 세 번째 모드 `🗼 랜드마크`
  - 수도 퀴즈와 같은 주요 50개국. 나라마다 대표 랜드마크 사진 1장을 크게 보여주고
    "이 랜드마크는 어느 나라에 있을까요?" 4지선다(보기는 나라 이름, 같은 대륙 우선)
  - 답하면 사진 위에 `[국기] 에펠탑 · 프랑스` 이름표가 붙고 "에펠탑은 프랑스에 있어요 🇫🇷"(국기는 SVG)
  - 단계·10문제·복습·결과·숫자키·소리는 수도 퀴즈와 같습니다. 기록은 `flagcards.landmarks`(📸)로 따로 저장
  - 사진을 못 불러오면 이모지 + 랜드마크 이름으로 대신 보여주고 퀴즈는 그대로 진행
  - `📷 사진 출처`를 누르면 나라별 촬영자·원본 링크(Commons는 라이선스까지)가 나옵니다

국기는 전부 페이지 안에 들어 있습니다. 랜드마크 사진만 같은 폴더의 `landmarks/*.webp`(50장, 약 3MB)를 부릅니다.

### 수도 표기 기준

국립국어원 외래어 표기법과 외교부 표기를 따랐고, 정답은 **하나**만 둡니다.

- **남아프리카 공화국 → 프리토리아**: 수도가 셋(행정 프리토리아·입법 케이프타운·사법 블룸폰테인).
  정부가 있는 행정수도를 정답으로 함
- **네덜란드 → 암스테르담**: 헌법상 수도. 정부·왕궁은 헤이그에 있지만 수도는 암스테르담
- **스위스 → 베른**: 법률상 "연방 도시"지만 사실상 수도로 통용
- **탄자니아 → 도도마**: 법률상 수도(정부 이전 완료). 최대 도시 다르에스살람과 헷갈리기 쉬움
- **말레이시아 → 쿠알라룸푸르**: 헌법상 수도. 정부 기관은 행정도시 푸트라자야로 옮겨 감
- **인도네시아 → 자카르타**: 누산타라로 이전을 진행 중이지만 법적 이전 완료(대통령령) 전이라
  국제적으로 자카르타가 통용. 이전이 확정되면 `capitals.json`만 고치면 됨
- **나이지리아 → 아부자**(라고스 아님), **튀르키예 → 앙카라**(이스탄불 아님),
  **호주 → 캔버라**(시드니 아님), **브라질 → 브라질리아**(리우 아님), **아랍에미리트 → 아부다비**(두바이 아님)
- **우크라이나 → 키이우**: 2022년 이후 국립국어원·외교부 표기(예전 "키예프")
- **싱가포르**: 도시국가라 수도 이름이 나라 이름과 같습니다(쉬운 문제로 둠)

이 퀴즈 범위 밖이지만 참고로, 볼리비아(수크레/라파스)·에스와티니(음바바네/로밤바)·
코트디부아르(야무수크로/아비장)·미얀마(네피도)·카자흐스탄(아스타나)도 같은 원칙
(법률상·행정 수도 하나)으로 넣으면 됩니다.

## 파일

| 파일 | 하는 일 |
|---|---|
| `index.html` | 페이지 본체. **Claude Artifact용 조각이라 `<head>`·`<body>`가 없습니다** |
| `flags.js` | 197개국 데이터(이름·대륙·난이도·SVG + 퀴즈 50개국의 수도 `p`/`pe`), 약 2.8MB |
| `capitals.json` | 수도 퀴즈 50개국의 수도(`code → {ko, en}`) |
| `landmarks.json` | 랜드마크 50곳(`code → {ko, en, emoji, search, photo_id, photographer, photographer_url, pexels_url 또는 source_url, license}`) |
| `landmarks/` | 랜드마크 사진 50장(`<code>.webp`, 긴 변 800px, WebP 80) |
| `fetch_landmarks.py` | 사진 수집·검수·압축 도구(Pexels 검색 → 컨택트시트 → 채택 → WebP). 키는 1번 폴더 `.env`를 읽기만 함 |
| `docs/` | GitHub Pages가 서비스하는 폴더. `build_pages.py`가 만듭니다 |
| `build_data.py` | flagcdn에서 국기를 받아 `flags.json`을 만듭니다 |
| `make_js.py` | `flags.json` + `capitals.json` + `landmarks.json` → `flags.js`. 수도 코드가 flags.json에 없거나, 50개가 아니거나, 빈 값·중복이 있으면 멈춥니다. 랜드마크도 나라 목록 일치·이름 중복·사진 파일·출처·라이선스를 검사합니다 |
| `verify/run_verify.py` | Playwright로 수도 퀴즈·카드 자동 검증(100판×6단계 시뮬레이션, 한 판 플레이, 레이아웃). 스크린샷도 `verify/`에 |
| `verify/run_verify_landmark.py` | 랜드마크 퀴즈 자동 검증(사진 50장 로딩, 100판×6단계, 한 판 플레이, 대체 화면, 출처, 레이아웃). 스크린샷 `verify/L*.png` |
| `build_pages.py` | `index.html`(조각) → `docs/index.html`(완전한 HTML), `flags.js`·`landmarks/`도 `docs/`로 복사 |

## 고칠 때

```bash
# 나라 목록이나 난이도를 바꾼 경우
python build_data.py     # 국기 내려받기 (인터넷 필요)
python make_js.py        # flags.js 다시 만들기 (수도를 고친 경우도 이것만)

# 화면을 고친 경우
python build_pages.py    # docs/ 갱신
python verify/run_verify.py            # 수도 퀴즈·카드 자동 검증(playwright 필요)
python verify/run_verify_landmark.py   # 랜드마크 퀴즈 자동 검증
git add -A && git commit -m "..." && git push

# 랜드마크 사진을 바꾸는 경우
python fetch_landmarks.py search fr --q "Eiffel Tower night"   # 후보 추가(Pexels)
python fetch_landmarks.py commons fr "Eiffel Tower"            # 후보 추가(Commons)
python fetch_landmarks.py sheet fr                             # 컨택트시트 → 눈으로 검수
python fetch_landmarks.py pick fr 3                            # 3번 채택(출처가 landmarks.json에 기록)
python fetch_landmarks.py build fr                             # landmarks/fr.webp
python make_js.py && python build_pages.py
```

**Artifact로 올릴 때**는 페이지(`index.html`)와 함께 `flags.js`와 `landmarks/*.webp` 50장을
같은 상대경로(`landmarks/kr.webp` …)로 `files`에 넣어야 합니다. 사진이 빠지면 퀴즈는 이모지 대체 화면으로 돕니다.

`index.html`을 직접 고치고 **`build_pages.py`를 돌리지 않으면 배포 페이지는 그대로입니다.**

## 알아둘 점

- `index.html`에는 `<!doctype>`·`<head>`·`<body>`가 없습니다. Claude Artifact가 게시할 때
  자동으로 씌워주기 때문입니다. GitHub Pages는 씌워주지 않으므로 `build_pages.py`가
  charset·viewport와 함께 감싸서 `docs/`에 냅니다. 조각을 그대로 올리면 한글이 깨집니다.
- 받아온 SVG의 절반쯤은 `viewBox` 없이 `width`/`height`만 갖고 있습니다. 그 둘을 지우면
  비율 기준이 사라져 국기가 확대되어 잘립니다. `make_js.py`가 지우기 전에 `viewBox`를
  만들어 넣습니다.
